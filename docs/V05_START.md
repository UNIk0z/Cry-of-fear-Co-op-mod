# Start here (v0.5)

Players: give them the player ZIP ("Cry of Fear Co-op v0.5.zip"). Each runs
"Install.cmd" (game closed), then double-clicks "Run Co-op Mod.cmd": the game
opens at the co-op main menu. "Check for Updates.cmd" looks for a newer release
on GitHub. The host can play alone. A friend clicks Join, types the host's IP,
then the port (or waits for 27015); the console `connect <host IP>:27015` still
works. "Uninstall.cmd" puts everything back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
