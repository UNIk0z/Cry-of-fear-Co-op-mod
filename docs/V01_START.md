# Start here (v0.1)

Players: give them the player ZIP ("Cry of Fear Co-op v0.1.zip"). Each runs
"Install or Update.cmd" (game closed); the host runs "Host a game.cmd", the
friend "Join a game.cmd". Uninstall.cmd puts everything back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
