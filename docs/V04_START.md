# Start here (v0.4)

Players: give them the player ZIP ("Cry of Fear Co-op v0.4.zip"). Each runs
"Install or Update.cmd" (game closed), then double-clicks "Run Co-op Mod.cmd":
the game opens at the co-op main menu. The friend joins from the game console
(~): connect <host IP>:27015. Uninstall.cmd puts everything back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
