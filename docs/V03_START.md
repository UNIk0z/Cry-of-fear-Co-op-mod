# Start here (v0.3)

Players: give them the player ZIP ("Cry of Fear Co-op v0.3.zip"). Each runs
"Install or Update.cmd" (game closed), then "Run Co-op Mod.cmd" (H = host,
J = join). Uninstall.cmd puts everything back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
